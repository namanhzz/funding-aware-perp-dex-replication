# Funding-aware market-making replication package

This public repository contains the data, code, frozen configurations, and
seed-level results used in **“Funding-aware optimal market making for
perpetual DEXs”** by Nam Anh Le.

All research materials are grouped in the single [`replication/`](replication/)
folder. See [`replication/README.md`](replication/README.md) for the exact
environment, commands, data provenance, and manifest-verification workflow.

The empirical application covers Hyperliquid ETH, BTC, and SOL perpetuals. The
principal evaluation spans 15 January–31 July 2026 and uses 100 paired Monte
Carlo seeds. A separate venue-native validation uses official Hyperliquid
15-minute candles and hourly funding over 18 June–31 July 2026.

## Public-repository statement

Evaluation data, calibrated inputs, source code, configuration files,
seed-level outputs, and a checksummed replication manifest are publicly
available in this repository.
